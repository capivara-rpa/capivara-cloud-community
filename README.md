# Capivara Cloud — Comunidade

Espaço para sugestões, RFCs, exemplos e conectores da comunidade do
**Capivara Cloud**, a plataforma de automação de APIs em português.

- Produto: <https://github.com/capivara-rpa/capivara-cloud>
- Documentação local: `docs/` no repositório do produto
- Discussões: use as **Discussions** deste repositório
- Bugs do produto: abra uma issue com o template de bug
- Ideias e RFCs: use `ideias/` e o template de sugestão
- Conectores: use `conectores/` e o template de integração

## Como contribuir

1. Leia `CONTRIBUTING.md` e `GOVERNANCA.md`.
2. Verifique se já existe issue/discussão sobre o assunto.
3. Para mudanças grandes, abra uma RFC em `ideias/` antes do código.
4. Para exemplos e conectores, mande um PR pequeno e testável.
5. Respeite o `CODE_OF_CONDUCT.md`.

## O que tem aqui

```text
.github/           templates de issue e PR
conectores/        propostas de conectores e integrações
ideias/            sugestões e RFCs
```
