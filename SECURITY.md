# Segurança

## Reportar vulnerabilidade

Não abra issue pública com detalhes de vulnerabilidade.

Envie um e-mail para **capivara@arthurfaria.tech** com:

- descrição do problema;
- passos para reproduzir;
- versão/commit afetado;
- impacto esperado;
- sugestão de correção, se tiver.

## O que esperar

- Confirmação de recebimento em até 5 dias úteis.
- Avaliação e priorização conforme impacto.
- Atualização quando houver correção ou mitigação.
- Crédito na divulgação, se você quiser.

## Escopo

Vale para o produto (`capivara-rpa/capivara-cloud`) e para este repositório de
comunidade.

## Boas práticas para contribuições

- Nunca inclua tokens, senhas, chaves ou dados de clientes.
- Use exemplos fictícios.
- Se um exemplo precisar de credencial, documente o formato, não o valor.
- Reporte qualquer vazamento acidental imediatamente.
