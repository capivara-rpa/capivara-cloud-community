# Ideias e RFCs

Use esta pasta para propostas que ainda não viraram código.

## Quando abrir uma ideia

- Uma funcionalidade nova que muda o produto.
- Uma mudança de arquitetura ou API.
- Um conector com regras de autenticação complexas.
- Uma mudança de processo da comunidade.

## Como abrir

1. Copie `TEMPLATE.md` para `ideias/minha-ideia.md`.
2. Preencha o problema, a proposta e os impactos.
3. Abra um PR.
4. A comunidade comenta por pelo menos 7 dias.
5. Os mantenedores decidem: `aceita`, `recusada` ou `precisa-de-mais-info`.

## O que uma boa ideia tem

- Problema real e específico.
- Público afetado.
- Alternativas consideradas.
- Impacto em API, dados e segurança.
- Plano de teste.
- Escopo pequeno o suficiente para o MVP.
